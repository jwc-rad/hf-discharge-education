## 작성 규칙

- 체크리스트는 `- [ ]` / `- [x]`로 관리하고, 담당자는 항목 끝에 `(@이름)`으로 표시한다.
- 완료 항목은 바로 지우지 말고 체크만 한다. 마일스톤이 끝나면 정리한다.
- 메모는 날짜(`MM-DD`)와 함께 각 파일 하단 **메모** 섹션에 추가한다. 회의 결정 사항도 여기에 남긴다.
- 파트 간 협의가 필요한 항목은 양쪽 파일에 모두 적고 서로 링크한다.
- **환자 데이터(MIMIC 노트, EHR 내용)는 메모에도 절대 쓰지 않는다.**
